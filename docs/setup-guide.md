# Corcell セッティングガイド

Corcell を使いはじめるときの、ケースまわりの手順です。
ファームウェアについては [README](../README.md) を参照してください。

## ボトムケースの取り外し

電池の交換と、XIAO へのアクセス（ファームウェアの書き込み、リセットボタン操作）には
ボトムケースを開けます。

1. キーボードを裏返し、平らな場所に置きます。
2. ボトムケースの縁に指をかけ、ケースを開きます。
3. 内部の基板とスイッチが見える状態になります。電池ホルダーと XIAO はこの面にあります。
4. 戻すときは、基板側とボトムケースの位置を合わせてから閉じます。

## チルトスタンドのサポート材除去

チルトスタンド部分は 3D プリントのサポート材が残った状態でお届けする場合があります。
使う前に取り除いてください。

https://github.com/user-attachments/assets/3976ca60-955a-4a11-b60c-074f46f67fc4

1. ニッパーの先を、サポート材とスタンドの隙間に入れます。
2. サポート材だけをつまんで、少しずつ切り離します。
3. 残った小さな破片も取り除き、スタンドが引っかかりなく動くことを確認します。

ケース本体を傷つけないよう、ニッパーはサポート材側だけをつまんでください。

## 電池について

左右それぞれに単四電池を 1 本ずつ入れます。
エネループなどの充電池でも、アルカリ乾電池でも使えます。

電池を入れると XIAO の緑 LED が 2 秒だけ点灯します。
点灯すれば、電池と昇圧回路が生きています。
