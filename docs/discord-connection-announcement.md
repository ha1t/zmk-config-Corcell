# Discord 告知案（現行配布版向け・未投稿）

Corcell の接続で迷ったら、まずここを確認してください。

**USB を挿すのは右手側です。** 右が親機で、左の入力も右を経由して PC へ送ります。USB 使用時も左右間は無線なので、左にも電源を入れてください。

**「USB で文字が打てる」と「USB で DYA Studio につながる」は別です。** 2026-09-05 の `c2c3cb8` までの DYA 版は、Studio 接続が Bluetooth 専用です。USB で Studio に接続できないのは、この版では仕様です。ポートが表示されても Studio 用ではありません。また、Bluetooth で文字が打ててもブラウザの候補に出ない環境があるため、その場合はファームの版をお知らせください。

初めて Bluetooth 接続する場合は、USB を外し、左右に電池を入れます。初期配列では、右親指のレイヤー 3 キー（Space と短押し A のキーの間）を押しながら、右上端の Backspace を押して接続先 0 を選び、PC／スマホの Bluetooth 設定から Corcell を追加してください。左右を別々に登録する必要はありません。

USB で文字が出ない場合は、右側・データ対応ケーブル・出力先を確認してください。Bluetooth に出力されていることもあるので、いったん接続中の機器の Bluetooth を OFF にして切り分けられます。

緑 LED が約 2 秒で消えるのは正常です。長く放置した後はキーを一度押して数秒待ち、もう一度入力してください。

Studio で `The port is already open` と出た場合は、まず Studio のタブをすべて閉じ、USB を抜き差しして、通常版の Studio を 1 タブだけ開いて接続し直してください。このエラーだけなら、設定初期化は不要です。

Windows で UF2 コピー中に `0x80070022` が出る場合は、書き込み後の自動再起動に伴う表示の可能性があります。ただし必ず成功とは限りません。コピー処理がエラーで止まり、基板が通常起動している場合はダイアログを閉じ、入力とファーム版を確認してください。左右や settings_reset をまとめず、その側の UF2 を 1 個ずつコピーします。

現在の DYA 版はファイル名に `dya-studio` が入ります。入っていない場合は、通常版をダウンロードしていないか Build のブランチを確認してください。古いファイルや改名したファイルは、名前だけでは判定できません。

解決しない場合は「OS」「ファームの配布元／Build」「USB を挿した側」「文字入力と Studio のどちらが反応しないか」「右だけ／左だけ／両方」を教えてください。

※ USB で Studio を使える接続改善版は検証中です。公開前のため、この案内は既存配布版の説明です。
